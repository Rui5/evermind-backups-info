A personal-use tool for Evermind

Encrypted backups.
Locally controlled.

Evermind Backups connects a privately operated Evermind installation to its owner’s Google Drive. Canonical data stays on the local Mac mini; backup contents are encrypted on that computer before upload.

Read how your data is handled ↗
Setup in progress. Encrypted backup and restore have passed a test using synthetic files. Automated backups and complete application recovery are still being prepared.

The backup path

One owner. Three stages.

  1. 01

    Keep the source local

    The privately operated Evermind installation holds the original knowledge, memories, and application state. This information site has no sign-in or upload form.

  2. 02

    Encrypt before upload

    The local backup workflow uses restic for encryption and rclone for Google Drive transport. Google stores encrypted backup objects and associated storage metadata.

  3. 03

    Restore with the key

    Recovery requires the encrypted repository and its recovery password. The owner must keep an independent copy of that password and verify recovery before relying on a backup.

Google Drive access

Permission for the files
the app uses.

The app requests the drive.file permission. It can create, read, update, and delete Drive files created by the app or explicitly authorized for use with it. This permission does not grant general access to every file in your Drive.

Account identity and storage-quota information are used to check the selected backup account and available capacity. The backup integration does not request Gmail or Google Contacts access.

Read the privacy policy before authorizing access. You can review or revoke the connection in your Google Account connections.

Questions about this app?

Evermind Backups is operated for a private household. Contact your household’s project operator using the support email shown on the Google consent screen.
